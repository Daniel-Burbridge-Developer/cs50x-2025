CS50x

Introduction to C programming. My first steps into programming with C - loops, variables, algorithms, and problem-solving. Built pyramids, implemented greedy algorithms, and validated credit cards using Luhn's Algorithm.

Cryptography and text analysis. Explored encryption with Caesar cipher and analyzed text readability. Learned about ASCII manipulation, command-line arguments, and applying mathematical formulas in code.

Algorithms and data structures. Implemented voting systems (plurality, runoff, Tideman) and analyzed sorting algorithms. Dove deep into arrays, structs, algorithm complexity, and graph theory.

Memory and multimedia. Manipulated images (filters, edge detection) and audio files, plus recovered deleted JPEGs. Learned about binary file I/O, 2D arrays, RGB color values, and digital forensics.

Pointers and dynamic memory. Simulated genetic inheritance and built a spell checker with hash tables. Mastered pointers, malloc, linked lists, and the trade-offs between memory and performance.

Transition to Python. Reimplemented C problems in Python, plus DNA sequence matching. Discovered Python's elegant syntax and powerful built-in functions. Much easier than C!

SQL and databases. Queried Spotify and IMDb databases, then solved the Fiftyville mystery using SQL detective work. Learned about relational databases, JOINs, subqueries, and data analysis.

Web development. Built an interactive trivia quiz and this personal homepage using HTML, CSS, JavaScript, and Bootstrap. The culmination of my CS50x journey - a portfolio showcasing everything I've learned!
