Problem Set 4

Image filtering fundamentals. Implemented grayscale, sepia, reflection, and blur filters for BMP images. This was my introduction to image manipulation, working with 2D arrays, and understanding RGB color values. Learned about pixel-by-pixel processing and the mathematics behind visual effects.

Advanced image filters with edge detection. Extended Filter-less with Sobel operator edge detection. This challenged me with more complex convolution algorithms and understanding how edge detection works in computer vision. Really cool to see how simple math can detect edges!

Digital forensics - recovering deleted JPEGs. Recovered deleted photos from a memory card by analyzing file signatures and block structure. This taught me about file systems, binary data, and how "deleted" files can be recovered. Felt like a real digital detective!

Audio manipulation with WAV files. Modified audio volume by reading and manipulating WAV file headers and sample data. This introduced me to audio file formats, binary file I/O, and how digital audio is stored. Learned that audio is just numbers that can be mathematically transformed!
