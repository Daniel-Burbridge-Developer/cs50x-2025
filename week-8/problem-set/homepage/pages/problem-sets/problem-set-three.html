Problem Set 3

Simple plurality voting system. Implemented a basic election where the candidate with the most votes wins. First time working with arrays, structs, and string comparison using strcmp. Learned about tallying votes and finding max values in arrays.

Ranked-choice voting with instant runoff. Implemented a more complex election system with voter preferences and elimination rounds. Multi-dimensional arrays and complex logic made this one pretty challenging. Interesting to simulate how real-world voting systems work!

Analyzing sorting algorithm efficiency. Identified which sorting algorithm was used (selection, bubble, or merge sort) by analyzing execution time and behavior. Got into Big O notation and algorithm complexity. Really eye-opening to see the practical differences between O(n²) and O(n log n) algorithms.

The Tideman ranked-pairs voting method. Implemented the most complex voting algorithm in CS50x, involving graph theory and cycle detection. This one was a serious challenge. Dove deep into advanced data structures, recursion, and some pretty sophisticated algorithmic thinking.
