Problem Set 5

Simulating genetic inheritance. Modeled how genetic traits are passed down through generations using linked data structures. This was my introduction to pointers, dynamic memory allocation with malloc, and working with tree structures. Fascinating application of CS to biology!

Building a spell checker with hash tables. Implemented a dictionary using hash tables for fast word lookup. This was one of the most challenging problems - dealing with memory management, hash functions, linked lists, and optimizing for performance. Learned about the trade-offs between memory and speed!
