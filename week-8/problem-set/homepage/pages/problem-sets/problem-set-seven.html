Problem Set 7

Introduction to SQL with Spotify data. Wrote SQL queries to analyze music data like songs, artists, and rankings. First time working with databases and SQL syntax. Picked up SELECT, WHERE, ORDER BY, and JOIN operations. Interesting to see how relational databases organize and query data!

Complex SQL queries with IMDb data. Queried a massive movie database to find connections between actors, directors, and films. Got into nested subqueries, multiple JOINs, and aggregate functions. Really saw the power of relational databases for complex data relationships!

SQL detective work - solving the Fiftyville mystery! Used SQL to investigate a crime by querying witness interviews, phone records, flight data, and ATM transactions. This was super fun, like being a detective using databases! Got into complex multi-table queries and saw how real investigations use data analysis.
