Problem Set 1

My first C program! Built a simple pyramid using nested loops and the # character. Got my first taste of loops, variables, and basic output in C. Also learned the hard way about input validation and edge cases.

The advanced pyramid challenge. Created the iconic Super Mario Bros. pyramid with both left and right sides. Figuring out the spacing and alignment was trickier than I expected, but it really helped me understand nested loops better.

Greedy algorithm implementation. Calculated the minimum number of coins needed to make change. First time thinking about algorithms and optimization. Picked up modulo operations and integer division along the way.

Credit card validation using Luhn's Algorithm. Implemented checksum validation and card type detection (Visa, MasterCard, AMEX). Pretty cool to see how the math behind credit card validation actually works. Dealt with large numbers and string manipulation in C for the first time.
