Problem Set 1

My first C program! Built a simple pyramid using nested loops and the # character. This was my introduction to loops, variables, and basic output in C. Learned how to handle user input validation and the importance of edge cases.

The advanced pyramid challenge. Created the iconic Super Mario Bros. pyramid with both left and right sides. This taught me about complex loop logic and how to manage spacing and alignment in console output. Definitely trickier than it looked at first!

Greedy algorithm implementation. Calculated the minimum number of coins needed to make change. This was my first exposure to algorithmic thinking and optimization. Learned about modulo operations and integer division in C.

Credit card validation using Luhn's Algorithm. Implemented checksum validation and card type detection (Visa, MasterCard, AMEX). This problem taught me about working with large numbers, string manipulation in C, and the importance of real-world algorithms in everyday technology.
