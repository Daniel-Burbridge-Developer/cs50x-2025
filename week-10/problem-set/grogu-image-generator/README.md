## 🎯 Objective

My Fiance sends her boss a Baby Grogu meme every morning. My goal is to automate this little job, and make it a little simpler. Could I expand this to other image types, and make it a flexible robust system? Sure.... But that's not what the Objective is. The Objective: Cute, Baby Yoda's, Daily to my Fiance's phone.

## 📋 Technical Specification

- Hugging Face for image generation
- Python Script
- CallMeBot for whatsapp messaging capabilities
- Self Hosted on HomeLab
